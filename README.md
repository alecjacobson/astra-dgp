# Bahen Centre — video-guided 3D reconstruction

Work in progress: an editable architectural model of the University of Toronto's Bahen Centre, using frames from [this walking tour, beginning at 14:52](https://www.youtube.com/watch?v=GGaJsGu_5zA&t=892s).

The workflow repeatedly renders the actual 3D geometry, compares it to reference frames, and receives independent visual review. Progress screenshots are published here approximately every ten minutes during active development. This is an inferred architectural reconstruction, not a measured survey.

Model, interactive viewer, build scripts, and review notes will follow.
